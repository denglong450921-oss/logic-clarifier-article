# Example — 用概率论证处理“深圳教育性价比高”

> 本例展示论证方法，不替代事实核查。实际使用时，方括号中的数据槽位应通过政府、教育部门、大型机构或可靠研究补齐。

## 1. 先降级过强命题

不直接证明：

> 深圳是全国教育性价比最高的城市。

因为这要求近乎全国范围的统一指标比较。

改为：

> 对已经在深圳稳定居住、能够获得公办学位的部分普通家庭，深圳教育可能具有较高性价比。

这样证据责任与现实可获得数据更匹配。

## 2. 定义“性价比”

```text
教育性价比
≈
孩子实际获得的教育价值
──────────────
家庭为此承担的总成本
```

进一步拆成：

```text
教育价值
≈
教育质量 × 实际可获得性 × 教育结果

家庭总成本
≈
直接教育费用 + 住房/通勤 + 校外教育 + 时间机会成本
```

## 3. 用反转测试筛出关键变量

### 变量 A：公共教育质量

如果深圳公共教育质量并不高，结论会明显变弱。

需要证据：

- [教育部门教师结构数据]
- [财政教育投入数据]
- [学校/课程资源数据]
- [可比的教育结果指标]

### 变量 B：家庭直接教育支出

如果公办教育、课后服务等并没有降低家庭支出，性价比论证会变弱。

需要证据：

- [官方收费政策]
- [课后服务政策与覆盖情况]
- [相关补贴政策]

### 变量 C：实际可获得性

城市有资源，不等于某个家庭拿得到。

需要证据：

- [招生/学位政策]
- [学位供给与在校生数据]
- [不同区域覆盖差异]

### 变量 D：住房与通勤等隐性成本

如果为了教育必须承担极高住房溢价，总性价比可能反转。

需要证据：

- [住房/租金公开数据]
- [典型通勤成本]
- [学位与居住绑定规则]

### 变量 E：升学路径风险

小学阶段资源好，不自动代表整个 K–12 路径都更划算。

需要证据：

- [中考/高中学位相关官方数据]
- [招生政策]
- [可比升学路径指标]

## 4. 证据更新

```text
初始：
“深圳教育性价比高”只是一个观点
↓
公共教育投入/师资数据较强
→ 可信度上调
↓
直接教育支出较低/公共服务覆盖较好
→ 再上调
↓
但住房成本很高
→ 下调
↓
如果目标家庭本来就在深圳稳定居住
→ 住房新增成本的重要性下降
↓
如果又能稳定取得公办学位
→ 可获得性风险下降
↓
得到“有条件成立”的结论
```

## 5. 最大反方

最强反方不是：

> 深圳也有差学校。

因为概率命题允许存在差学校。

更强的反方是：

> 深圳的住房、学位获取和后续升学竞争成本，可能高到抵消公共教育资源优势。

这会真正影响结论，因此必须正面处理。

## 6. 最终有限结论

在实际数据支持的前提下，更稳妥的表述应类似：

> 对已经在深圳稳定居住、额外住房成本可控、且能够稳定获得公办学位的家庭，如果官方数据同时显示公共教育投入、师资和校内公共服务具有较强水平，那么“留深圳具有较高教育性价比”这一判断会得到较强支持；但这不能直接推出“深圳全国第一”，也不能自动适用于需要高价购房获取学位或升学路径明显不匹配的家庭。

## 7. 60 秒表达版

```text
结论：
对一部分已经在深圳扎根的普通家庭，
留深圳读书可能是高性价比选择。

为什么？
↓
第一：公共教育资源是否足够好
→ 看官方投入、师资和教育结果数据

第二：家庭直接教育支出是否可控
→ 看公办收费、补贴、课后服务

第三：这些资源我家是否真的拿得到
→ 看学位与招生政策

最大反方：
住房和升学路径成本会不会把优势吃掉？

如果家庭本来就在深圳、住房增量成本低、学位稳定，
这个反方影响会下降。

所以结论不是“深圳全国最好”，
而是“对这类家庭，留深圳更可能划算”。
```
