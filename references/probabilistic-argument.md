# Probabilistic Argument Engine

用于现实世界的论证构建，而不是恢复原作者的论证。

核心原则：

> 现实论证通常不是穷尽所有因素后证明“必然正确”，而是在明确范围内，用关键变量、可靠证据、合理机制和主要反证处理，把结论提升到“足够可信”。

## 1. 限定命题

先写清：

```text
谁？
什么时间？
什么范围？
比较对象是谁？
“更好 / 更划算 / 更有效”具体指什么？
```

把证据承担不起的强命题降级。

例：

```text
过强：
深圳是全国教育性价比最高的城市

可论证：
对已经在深圳稳定居住、能够获得公办学位的部分普通家庭，
深圳可能具有较高的教育性价比
```

## 2. 校准结论强度

```text
可能
< 较可能
< 通常
< 大多数情况下
< 高度确定
< 必然 / 所有 / 全国第一
```

结论越强，举证责任越高。

## 3. 用“反转测试”筛关键变量

不要问：

> 还有没有别的因素？

永远有。

改问：

> 如果这个变量不存在、方向相反或数值显著变化，核心结论会不会反转或明显降级？

```text
候选变量 X
↓
若 X 改变
↓
结论明显改变？
├─ NO → 次要变量
└─ YES → 关键变量
```

多数现实论证只保留 3–5 个决定性变量。

## 4. 建立最小充分证据集

```text
核心主张
│
├─ 关键事实：现象真的存在吗？
├─ 机制：为什么这些事实支持结论？
├─ 比较基准：相对什么更好/更差？
└─ 主要反证：最强反方能否推翻？
```

证据角色区分：

1. **硬数据**：政府、监管、官方统计、原始政策、大型机构/研究。
2. **稳定事实**：低争议背景。
3. **机制证据**：说明 A 为什么推动 B。
4. **案例**：说明“可能发生”，不能单独承担普遍结论。

优先组合：

```text
数据证明“存在”
+
机制解释“为什么”
+
比较说明“相对优势”
+
反证处理“边界”
+
案例帮助“看懂”
```

## 5. 做证据更新，不假装绝对证明

```text
初始判断
↓
E1 支持 → 上调
↓
E2 独立支持 → 再上调
↓
E3 反证 → 下调
↓
替代解释被削弱 → 再上调
↓
形成有限结论
```

注意：

- 同一原始来源的多个转载不算多份独立证据。
- 没有统计模型时只做定性更新。
- 不制造“83% 正确”之类伪精确概率。
- 若支持与反对证据都强，明确写“证据混合 / 结论仍不稳定”。

## 6. 钢人化最强反方

不要找最弱反驳。

问：

```text
最强替代解释是什么？
↓
它能解释同一批事实吗？
├─ 能，而且更好 → 降低/撤回结论
└─ 不能完全解释 → 原结论可信度上升
```

反例的任务是校准边界，不是无限推翻概率命题。

## 7. 停止规则

满足以下条件即可停止：

- 3–5 个最可能改变结论的变量已覆盖；
- 核心变量有事实依据或明确标记缺证；
- 最强反方已处理；
- 新因素只会微调，不太可能使结论反转；
- 新资料开始重复同类证据。

目标是 **minimum sufficient argument**，不是百科全书。

## 8. 快速表达版

用于争论、口播、短视频：

```text
结论是什么？
↓
适用范围是什么？
↓
判断标准是什么？
↓
最重要的 3 个理由
↓
每个理由 1 个最强证据
↓
最大反方
↓
它是否足以推翻？
↓
有限结论
```
