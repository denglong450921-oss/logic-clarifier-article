## 1. 先给核心判断

**这篇材料表面在讲：** …

**真正回答的问题是：** …

**作者的核心答案是：** …

> 一句话：……

## 2. 总逻辑图

```text
现象/困惑
↓
常见解释
↓
作者指出问题
↓
新解释/核心变量
│
├─ 判断 1
├─ 判断 2
└─ 判断 3
↓
统一结论
```


## 5. 它们其实是什么关系？

优先尝试：

```text
该不该做？ → 判断器 A
↓
在哪里做？ → 判断器 B
↓
投多少/做多久？ → 判断器 C
↓
反馈与迭代
```

如果只是并列，明确说并列。

## 9. 如果任务是“帮我论证 / 证明一个现实观点”

优先切换到概率论证模板：

### 命题边界

**我要论证：** …

**适用人群/时间/条件：** …

**比较对象：** …

**判断标准：** …

### 3–5 个决定性变量

```text
变量 A
├─ 最强事实/数据：…
└─ 机制：为什么支持结论？

变量 B
├─ 最强事实/数据：…
└─ 机制：为什么支持结论？

变量 C
├─ 最强事实/数据：…
└─ 机制：为什么支持结论？
```

### 证据更新

- **支持证据：** …
- **削弱证据：** …
- **证据是否独立：** …
- **当前置信判断：** 可能 / 较可能 / 通常 / 高度支持

不要在没有统计依据时给出伪精确百分比。

### 最大反方

**最强反对意见：** …

**它会不会让结论反转：** …

**因此需要增加的边界：** …

### 最终有限结论

> 在……条件下，根据……证据，这个观点目前“较可能 / 通常 / 高度支持”成立；但它不等于……

### 快速表达版

```text
结论
↓
范围
↓
3个最强理由
↓
每个理由1个最强证据
↓
最大反方
↓
有限结论
```
